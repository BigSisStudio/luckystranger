Typography

The font system.

Four typefaces, each doing a specific job — from headlines and signage down to menu copy and utility text. Below is how they perform together in context.

Gill Sans Bold · Gill Sans Semibold · Gibson Script · GIN

Signage / headlines

Gill Sans Bold

The workhorse. Utilitarian with real weight — the kind of type you'd see stenciled above a bar or hand-painted on a roadside sign. Pulls off the tongue-in-cheek hotel signage register without trying too hard.

Script accent

Gibson Script

The handshake. A simple hand-drawn script for accent words — the kind that shows up next to the bold in vintage type pairings. Friendly without being precious. Used sparingly: a word, a phrase, never a paragraph.

Body copy

Gill Sans Semibold & Regular

Matches the sans in the signage DNA. Readable at menu scale, legible in low light, consistent with the overall register. The Semibold for labels and callouts; Regular for descriptions and longer reads.

Emphasis / accent

GIN

The same face used for "Stranger" in the logo lockup. Used sparingly — a word that needs visual punch, a label that earns a second look. Not for running text. Not for signage. Just the moments that need it.

Note on web implementation These fonts aren't readily available as web fonts. Once the system is approved, we'll identify complementary Google Font pairings that capture the same register and can be cleanly implemented across the site and digital touchpoints.
